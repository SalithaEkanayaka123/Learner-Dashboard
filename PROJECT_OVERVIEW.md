# Learner Dashboard Project Overview

## Product Summary
Luma is a learning dashboard designed to help students turn notes, readings, and study material into measurable understanding. The product focuses on identifying knowledge gaps, improving confidence, and supporting adaptive learning.

## Core User Flow
1. User lands on the home page.
2. They choose to sign in or start learning.
3. They log in through the authentication screen.
4. They reach the dashboard overview.
5. They view their next assessment, confidence score, and uploaded learning sources.
6. They can add or manage study sources.
7. They continue learning and improve their understanding over time.

## Main Pages
- Home page: introduction and marketing content
- Login page: sign-in form
- Dashboard: overview of progress and upcoming assessment
- Upload page: add source files for learning materials

## Current State
This project is currently a frontend prototype built with Next.js. It demonstrates the intended user experience and navigation flow, but does not yet include backend authentication, real data persistence, or full assessment logic.

## Notes
The app architecture is simple and route-based:
- / -> landing page
- /login -> sign in
- /dashboard -> main learner dashboard
- /upload -> source upload flow

This gives a clear product structure for future expansion into real student data, file processing, adaptive testing, and analytics.
